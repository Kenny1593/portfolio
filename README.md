# Portfolio — Kenny Tokiniaina

Portfolio statique responsive pour un profil Développeur Full Stack.

## Lancer le portfolio
Ouvrir `index.html` dans un navigateur.

## À personnaliser
Dans `index.html`, remplace :
- `votre.email@example.com` par ton adresse e-mail
- les liens GitHub et LinkedIn
- le lien du bouton CV par ton fichier PDF
- les projets et descriptions selon tes réalisations

## Structure
- `index.html` : contenu
- `style.css` : design responsive
- `script.js` : menu mobile + animations
